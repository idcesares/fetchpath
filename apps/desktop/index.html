Checking the engine…

Closing this window keeps the queue available from the notification area.

Downloads belong to Fetchpath's engine, not to this window, so they continue after the desktop and tray exit. Choose Show Fetchpath from the tray icon to bring this window back.

Stop Fetchpath's engine?

Downloads stop now and wait in the queue. They continue from their saved progress when you start the engine again, and schedules do not run while it is stopped.

To keep downloading and only hide this window, use Close window instead.

      Rules

      Rules choose where a new download goes and how, by its site, file type or size. They are tried in order and the first that matches decides, for downloads from this window, your browser, the command line and agents. A folder you choose yourself always wins.

        Add a rule

        A site also covers its subdomains. Separate several with commas.

        A size rule applies only when the website says how big the file is.

          Cache

          When you give a checksum, Fetchpath keeps a copy of the verified file. Downloading the same file again finishes from that copy, checked again, without using the network.
