WELCOME

Three things worth knowing

  1. Paste a link and choose where it goes. Fetchpath saves to your Downloads folder unless you pick somewhere else. It never overwrites a file that is already there.
  2. Video and audio need two extra programs. Fetchpath does not include yt-dlp and ffmpeg. Set them up once from Settings.
  3. Closing the window keeps the queue running. Fetchpath stays in the notification area. You can change that in Settings.
